A one-line roast of the toaster I use every morning, written to entry.txt by a deterministic Python program.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes a single 73-character line to `out/entry.txt`: "My toaster has two settings: warm bread, and charcoal with a smoke alarm." It uses only the Python standard library, needs no network, and writes the same bytes on every run.
